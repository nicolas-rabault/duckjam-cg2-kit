# duckjam-cg2-kit

A public Duck Jam submission kit, created for the network test of task CG2 of the Duck Jam project:
the Arena's gate accepts a GitHub repository at a commit, bound to the GitHub handle the
submitter's Hugging Face profile declares.

It holds what a submission holds and nothing more: `duckjam.toml` naming the round and the entry,
the entry itself, and the Apache-2.0 licence the template carries — which the gate records on the
submission row as the third condition of a policy's route to a real robot.
